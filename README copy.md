# Grow

Application locale de suivi des pesées et des courbes de croissance pendant une hospitalisation.

## Utilisation

Ouvrir ce dossier dans Visual Studio Code. Pour tester correctement le fonctionnement hors ligne, lancer le dossier avec une extension de serveur local telle que Live Server, puis ouvrir `index.html`.

Les données sont conservées uniquement dans le navigateur utilisé. Aucun nom, prénom ni date de naissance complète n'est nécessaire.

## Publication GitHub Pages

Déposer le contenu du dossier dans un dépôt GitHub, puis activer GitHub Pages sur la branche principale et le dossier racine.

Les courbes intégrées proviennent des documents AFPA-CRESS/Inserm-CGM 2018 fournis pour les filles et les garçons.
